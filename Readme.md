# PFS CO Data

This folder contains notebooks, scripts, processed observation logs, release summaries, and local working outputs for exploring PFS SSP cosmology data. The top-level layout is kept intentionally lightweight: reusable code and active notebooks live under `src/`, processed obslog products live under `obslog/`.

NOTE: tutorial jupyternote on SP is very useful to check if you want to learn more about the data.

## Folder Structure

| Path | Contents |
| --- | --- |
| `src/` | Main notebooks and analysis scripts for release checks, coadd summaries, and target/data joins. |
| `obslog/` | Raw obslog folders, processed obslog CSV outputs, and obslog processing utilities/configs. |
| `data/` | Local data products and reference files. This folder is ignored by git. |
